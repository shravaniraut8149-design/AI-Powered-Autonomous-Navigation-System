03 / SYSTEM DESIGN

A modular architecture.

The project brief describes a pipeline from environment input through perception and planning to navigation output.

01Environment inputGrid map + start/goal
→
02World representationFree cells / obstacles
→
03A* path plannerCost + heuristic search
→
04Navigation outputRoute + agent animation

01 Perception layer

In this virtual version, map cells act as the environment observation. Future work can replace this with OpenCV camera frames, lane detection, and YOLO object detection.

02 Planning layer

A* uses path cost plus a heuristic estimate to prioritize promising cells. Obstacles are excluded from valid transitions.

03 Control layer

The browser animation advances the agent one route cell at a time. Physical motor control is intentionally outside this simulation.
